# Política de privacidad de Modas Nicolas

Última actualización: 12 de noviembre de 2026

Modas Nicolas es una app para llevar las cuentas diarias de una tienda. Esta página explica qué datos usa la app y dónde se guardan.

## Datos que no recopilamos

- La app no pide cuenta, registro ni inicio de sesión.
- No recopilamos datos personales ni datos de uso.
- No incluimos publicidad, analítica ni seguimiento de terceros.
- No vendemos ni compartimos datos con nadie.

## Dónde se guardan tus datos

Todo lo que apuntas (ventas, gastos, cobros con datáfono, inversiones y proveedores) se guarda solo en tu dispositivo, en una base de datos local. No se envía a ningún servidor nuestro.

## Copias de seguridad

Cuando exportas una copia de seguridad, la app crea un archivo con tus datos y abre el menú de compartir del sistema. Tú decides dónde guardarlo o a quién enviarlo. Al restaurar una copia, el archivo que eliges se lee en tu dispositivo.

## Conexión a internet

La app solo se conecta a internet para descargar el calendario de festivos nacionales de España desde `calendariosnacionales.com`. En esa petición solo se indica el año; no se envía ningún dato tuyo ni de tu negocio.

## Borrar tus datos

Como los datos solo están en tu dispositivo, al desinstalar la app se borran. Las copias de seguridad que hayas exportado quedan donde las guardaste.
